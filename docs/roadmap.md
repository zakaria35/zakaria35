# خارطة طريق كيميا 🧪

بناءٌ على مراحل، كل مرحلة **ناتجٌ صالح للاستخدام بذاته** ومادّةٌ أوّلية للتي تليها. لسنا متعجّلين — وهذا ما يجعل النتيجة متينة.

---

## المرحلة 1 — القلب: الصديق الذي يتذكّرك 🚧

**الهدف:** وكيلٌ على تيليجرام بشخصية «كيميا»، معلّم الكيمياء لطالب التوجيهي، مزوّد بذاكرة.

**المخرجات:**
- [x] شخصية الوكيل و System Prompt (`persona/kimya-system-prompt.md`)
- [ ] بوت تيليجرام كواجهة محادثة
- [ ] محرّك AI (نموذج محادثة) موصول بالشخصية
- [ ] ذاكرة محادثة (قصيرة المدى أولاً، ثم دائمة عبر جداول بيانات)

**الأدوات:** n8n (AI Agent + Telegram Trigger + Memory) · نموذج لغوي · بوت تيليجرام.

**معيار النجاح:** الطالب يحاور كيميا يومياً، ويشعر أنه يتذكّر سياق محادثاتهم.

---

## المرحلة 2 — العقل الباحث الموثوق ⏳

**الهدف:** يتحوّل كيميا من محاورٍ لطيف إلى باحثٍ يستشهد بمصادره، مع تحقّقٍ كيميائي.

**المخرجات:**
- [x] أداة تحويل المنهاج إلى نصّ يقرأه الوكيل — MarkItDown (`tools/markitdown/`)
- [ ] بناء قاعدة معرفة من الكتاب الوزاري والامتحانات السابقة (`knowledge/`)
- [ ] وصل قاعدة المعرفة بعقدة الوكيل كأداة بحث في n8n
- [ ] بحث ويب موثّق (Tavily/Exa) + قراءة عميقة (Fetch)
- [ ] تكامل PubChem لضمان صحة المعادلات والمركّبات
- [ ] قاعدة صارمة: كل معلومة علمية بمصدر

**لماذا المنهاج أولاً:** البحث في الويب يجيب عن «ما الاتزان الكيميائي؟»، لكن الطالب يريد الجواب **كما في كتابه الوزاري** لأنه سيُمتحن فيه. لذلك تسبق قاعدة المنهاج أدوات الويب لا العكس.

**معيار النجاح:** لا معلومة كيميائية تخرج دون تحقّق؛ الطالب يثق بدقّتها للامتحان.

---

## المرحلة 3 — مدير الأصول الرقمية ⏳

**الهدف:** كيميا ينظّم أصولك الرقمية تحت إدارة واحدة ذكية.

**المخرجات:**
- [ ] تكامل Google Drive (تنظيم وأرشفة وبحث)
- [ ] Canva (تحويل المحتوى لبطاقات بصرية بهوية ثابتة)
- [ ] Gmail + Calendar (فرز البريد وجدولة اليوم)
- [ ] Notion كعقلٍ ثانٍ مرئي

**معيار النجاح:** ملفاتك ومهامك منظّمة تلقائياً بلا جهد يدوي.

---

## المرحلة 4 — مدير السوشيال ميديا ⏳

**الهدف:** محرّك محتوى كيميائي يولّد ويصمّم ويجدول وينشر، بإشراف n8n.

**المخرجات:**
- [ ] أنماط محتوى: «تفاعل اليوم» · «كيمياء من حولك» · «خطأ شائع»
- [ ] طبقة تحقّق علمي قبل كل نشر
- [ ] جدولة ونشر عبر n8n على تيليجرام
- [ ] توسّع تدريجي: واتساب ← فيسبوك ← انستقرام

**معيار النجاح:** محتوى منتظم صحيح علمياً وجذّاب، ينشر شغف الكيمياء بلا إشرافٍ يومي.

---

## المبادئ الحاكمة

1. **الذاكرة أولاً** — بلا ذاكرة لا يوجد «صديق».
2. **المصداقية غير قابلة للتفاوض** — التخمين في الكيمياء خطر.
3. **طبقةً فوق طبقة** — كل مرحلة تعمل وحدها قبل الانتقال.
4. **الطالب أولاً** — كل قرار تصميم يُقاس بـ: هل يجعله يفهم أكثر ويخاف أقل؟
