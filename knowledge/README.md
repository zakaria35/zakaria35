# قاعدة معرفة كيميا 📚

المادّة الخام التي يستند إليها كيميا حين يجيب: الكتاب الوزاري، الامتحانات السابقة، أوراق العمل.

| المجلّد | المحتوى | يُرفع لـGit؟ |
| --- | --- | --- |
| `raw/` | الملفات الأصلية كما هي (PDF · Word · PowerPoint · صور) | ❌ لا |
| `md/` | مخرجات التحويل إلى Markdown + `INDEX.md` | ✅ نعم |

`raw/` **مستثنى من Git** عمداً: ملفات المنهاج ثقيلة، وحقوق نشرها ليست لنا. كل جهاز يحتفظ بنسخته المحلّية، والمشترك بيننا هو النصّ المحوّل في `md/`.

## سير العمل

```
ضع الملفات في knowledge/raw/
        ↓
python3 tools/markitdown/ingest.py
        ↓
راجع المخرجات في knowledge/md/  ← خطوة بشرية غير اختيارية
        ↓
اعتمدها مرجعاً لكيميا (المرحلة 2)
```

**المراجعة البشرية ليست تحصيل حاصل:** التحويل الآلي قد يشوّه معادلة كيميائية أو يخلط ترتيب جدول. راجع [`../tools/markitdown/README.md`](../tools/markitdown/README.md) لتفاصيل الأداة وحدودها.
