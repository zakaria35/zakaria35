# كيميا 🧪 — مساعد ذكاء اصطناعي شخصي للكيمياء

**كيميا** وكيلُ ذكاءٍ اصطناعيّ شخصيّ، صُمّم ليكون **صديقاً ومعلّماً** لطلبة الثانوية العامة (التوجيهي) في المنهاج الفلسطيني — مادّة الكيمياء، ثم ليتوسّع لاحقاً إلى **باحثٍ موثوق، ومدير أصولٍ رقمية، ومدير سوشيال ميديا**.

الفلسفة الحاكمة: **الذاكرة قبل كل شيء.** ما يحوّل الأداة إلى صديقٍ مواكب هو أن يتذكّرك. لذلك يُبنى كيميا طبقةً فوق طبقة، لا دفعةً واحدة.

---

## الجمهور المستهدف (المرحلة الأولى)

طلبة **الصف الثاني عشر (التوجيهي) — الفرع العلمي**، المنهاج الفلسطيني، مادّة الكيمياء، استعداداً للامتحانات الوزارية.

## المقر الأول

**تيليجرام** — الطالب يحاور كيميا من هاتفه كأي صديق. الأسهل تقنياً والأقرب للاستخدام اليومي.
